## SZS Pro Max- 在线三中杀桌游模拟器


一个基于 Node.js + Socket.io 的轻量级在线卡牌游戏联机平台。
支持多房间、实时拖拽交互、身份局逻辑、以及完整的卡牌操作（判定、装备、手牌管理）。无需复杂的客户端安装，浏览器即开即玩。适合朋友间进行“云桌游”聚会。

            
### 🚀 快速开始 (我是房主)

作为房主，你需要在一台电脑上运行服务器。

1. 环境准备确保你的电脑安装了 Node.js (版本 v14 以上)。下载地址: https://nodejs.org/


2. 安装依赖下载本项目代码，解压后在项目文件夹内打开终端 (CMD / PowerShell / Terminal)，运行：```npm install```


3. 启动游戏在终端运行：`npm start`看到输出 http://localhost:3000 即表示服务器启动成功。


4. 进入游戏房主/本机：浏览器访问 http://localhost:3000


### 🕶 远程联机教程

如果朋友不再同一个 WiFi 下，你需要使用内网穿透工具将你的本地服务器暴露到公网。这里使用 Cpolar 作为示例。

方案 A：使用 Cpolar (推荐国内用户)

1. 下载安装解压 Cpolar。https://www.cpolar.com/

2. 连接账户：在 Cpolar 的后台网页，找到 “验证” (Auth) 栏目。你会看到```./cpolar authtoken xxxxxxx...```，点击复制。

3. 双击打开你刚才解压的 cpolar.exe，会打开一个命令行窗口。

4. 在命令行窗口中，输入你之前复制的 authtoken 命令：`./cpolar authtoken xxxxxxx...`如果显示 `Authtoken saved`，说明成功。（2-4仅需做一次）

5. 启动服务器 (npm start) 不要关闭。打开 Cpolar，输入命令映射端口：`cpolar http 3000`。成功之后你会看见：
```
Status      online
Account     你的名字
Web Interface http://127.0.0.1:4040
Forwarding  http://62a8xxxx.cpolar.io -> http://localhost:3000
Forwarding  https://62a8xxxx.cpolar.io -> http://localhost:3000
```
复制 http://62a8xxxx.cpolar.io 网址，发给朋友点击进入即可开始联机。

### 🎮 游戏操作指南基本交互：

摸牌：左键单击牌堆

捡弃牌：左键点击弃牌堆然后选中想要的牌

打出牌：拖动卡牌到桌面中央绿色的“打出区”。

使用牌：拖动卡牌到桌面中央红色的“使用区” -> 点击目标头像 -> 点击右下角确认。

弃牌：拖动卡牌到弃牌堆（垃圾桶图标）。

给牌：直接将牌拖到其他玩家手牌区。

装备/判定/角色旁牌堆：直接将牌拖到自己或他人的对应区域（判定区/装备区/角色旁）。

切换角色旁牌堆可见性：左键单击在均不可见/仅自己可见/均可见之间切换

展示：将自己或别人的手牌拖入展示区

翻面/翻回、重置/横置、死亡/复活：点击相应的按钮

调整血量/血量上限：点击相应的加减号

添加/减少自定义标记：点击加号/右键点击需要去除的标记

右键菜单：
手牌：印卡（虚空造牌）

牌堆：摸底牌、判定（翻开顶牌）。

房主权限：点击顶部“设置”可配置身份数量（主/忠/反/内）和选将模式（X选Y）。

拥有“强制开始”和“撤销操作”权限。
